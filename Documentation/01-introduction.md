# Introduction

This document introduces the Altera® Sensor Link, an edge platform for deterministic ingestion, lightweight conditioning, and unified delivery of heterogeneous sensor data to a host over a high-speed Ethernet link using RoCEv2. The FPGA consolidates reliable sensor capture, optional hardware timestamping, format normalization, and edge pre-processing into a single device, providing the high-bandwidth, low-latency data path required for downstream processing on the host. Sensor sources such as cameras, lidar, radar, odometry, and IMU devices can be connected through dedicated FPGA resources, conditioned as required, and presented to the host as a coherent set of data streams.

The Sensor Link builds on Altera® IP and establishes capabilities in image signal processing, sensor ingestion, and high-speed networking. RoCEv2 carries InfiniBand-style transport over standard Ethernet and enables RDMA-based communication between the FPGA and host. In the Sensor Link, RoCEv2 is used to allow the host to consume sensor buffers with minimal copy overhead, supporting the bandwidth and latency requirements of multi-stream camera lidar and IMU data.

This release implements unidirectional data streaming using the Unreliable Connection (UC) transport from an Agilex™ 5 Modular Development Kit to a host over a 10 GbE link. The reference design provides five streams: two 1080p video streams at 30 frames per second, sourced from two IMX678C Framos sensors or generated by an internal test-pattern generator; one raw two-dimensional lidar data stream from an RPLIDAR A1M8 operating at approximately 5.5 Hz or generated by a test-pattern source; and two raw 64-bit streams from a Livox MID-360S (this includes 2.1kHz 96-point point cloud data and a 133Hz IMU data), brought in by Ethernet Ingest. The two-dimensional lidar, the point cloud, and the IMU are forwarded without transformation. The video streams are assigned to RoCEv2 Queue Pairs 0x2 and 0x3, the two-dimensional lidar stream to Queue Pair 0x4, the Livox MID-360S point cloud to Queue Pair 0x5, and the IMU from that same lidar to Queue Pair 0x6. These queue pairs can be changed using the Control Link over UDP provided in this release.

The design also associates captured sensor data with a common internal timestamp using the IEEE 1588 96-bit timestamp format. The timestamp synchronizes over PTP, a fabric(soft) implementation allows the FPGA global clock to synchronize to a host clock interchanging PTP messages, providing a common time reference for correlating data across the different sensor streams.

This release includes the ability to read and write any IP register in the FPGA using the “Altera Control Link” library. A UDP-based protocol that allows non-roce communication between the host and the FPGA to configure the hardware in the FPGA design. The function of the FPGA will not initiate until the host is able to configure it using such provided mechanism.

The design is released as an SOF (SRAM Object File), which is the FPGA configuration image used to program the Agilex 5 device. Altera retains the rights to the source code used to generate the SOF binaries. Because the included IP and system components have not reached the quality, validation, and hardening levels required for production deployment, this design is provided strictly as a proof-of-concept release and must not be represented or advertised as a production-ready solution.
